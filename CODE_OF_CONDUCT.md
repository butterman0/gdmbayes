# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be respectful and constructive; harassment, discrimination and personal
attacks are not tolerated in issues, pull requests or any other project space.

Instances of unacceptable behaviour may be reported to the maintainer at
harryhorsley9@gmail.com. Reports are handled confidentially.
